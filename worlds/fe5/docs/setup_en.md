# Fire Emblem: Thracia 776 setup status

This integration is under development. There is no playable release yet.

The planned workflow is to install `fe5.apworld`, generate a player patch, apply
it to the exact supported Lil' Manster 1.08 ROM locally, then run the resulting
ROM in BizHawk and connect through SNI with the Thracia handler. Concrete install
steps and supported versions will be added after end-to-end validation.
